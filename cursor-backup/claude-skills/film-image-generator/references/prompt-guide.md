# Image Prompt Guide

## Anatomy of a Great Prompt

### Base Elements
1. **Subject** - Who or what is the focus
2. **Action** - What is happening
3. **Setting** - Where is it happening
4. **Camera** - How is it framed
5. **Lighting** - How is it lit
6. **Mood** - What feeling
7. **Style** - What aesthetic
8. **Technical** - Format specs

### Order of Elements
```
[Subject with details]
[Action/Movement]
[Setting/Environment]
[Camera/Framing]
[Lighting Quality & Direction]
[Mood/Atmosphere]
[Style/Genre]
[Technical Specs]
```

## Prompt Engineering Tips

### DO
- Be specific about subjects
- Include camera angles
- Describe lighting precisely
- Add mood/emotion words
- Specify aspect ratio
- Include style references
- Add technical terms

### DON'T
- Be too vague
- Contradict yourself
- Overload with keywords
- Use negations (not, without)
- Mix conflicting styles

## Camera Terms

### Shot Types
| Term | Meaning |
|------|---------|
| EWS | Extreme Wide Shot |
| WS | Wide Shot |
| MS | Medium Shot |
| MCU | Medium Close-Up |
| CU | Close-Up |
| ECU | Extreme Close-Up |
| OTS | Over-the-Shoulder |

### Movements
| Term | Meaning |
|------|---------|
| Static | No movement |
| Tracking | Moving with subject |
| Dolly | Moving toward/away |
| Pan | Horizontal sweep |
| Tilt | Vertical sweep |

### Lenses
| Lens | Effect |
|------|--------|
| Wide (14-24mm) | Epic, distorted |
| Normal (35-50mm) | Natural |
| Portrait (85-135mm) | Compressed, flattering |
| Telephoto (200mm+) | Compressed, distant |

## Style References

### Cinematic
```
cinematic, film grain, 35mm, anamorphic lens,
2.39:1 aspect ratio, color grading, movie still
```

### Documentary
```
documentary style, handheld, natural lighting,
available light, candid, realistic, 16:9
```

### Fashion
```
high fashion, editorial, studio lighting,
clean background, magazine quality, 4:5
```

manga panels, Japanese animation influence
```

### Oil Painting
```
classical oil painting, Rembrandt lighting,

## Technical Specifications

### Aspect Ratios
```
2.39:1  - Cinematic scope
1.85:1  - Flat cinema
16:9    - Standard video
4:3     - Vintage TV
1:1     - Square
9:16    - Vertical story
```

### Quality Modifiers
```
photorealistic, 8k, ultra detailed, professional,
high budget production, award winning cinematography
```

## Example Prompts

### Example 1: Thriller Scene
```
Close-up of woman's face in dim apartment, fear in
her eyes, single candle creating flickering light on
left side casting long shadows, shallow depth of field,
cinematic mood, film noir style, 2.39:1, photorealistic
```

### Example 2: Action Shot
```
Wide shot of car chase through downtown streets at
night, neon signs reflecting on wet pavement, drone
view following black sedan, motion blur on background,
action movie aesthetic, Fast & Furious style,
2.39:1 cinematic, vibrant night lighting
```

### Example 3: Romantic Scene
```
Two elderly couple sitting on park bench at sunset,
golden hour warm light on their faces, gentle smile,
holding hands, shallow depth of field, bokeh background
with out-of-focus trees, nostalgic and tender mood,
cinematic color, 1.85:1, emotional, real film look
```

### Example 4: Horror Scene
```
POV shot looking down dark basement stairs, single
flickering bulb at top casting moving shadows on
concrete walls, ominous atmosphere, tension in framing,
wide angle lens creating distortion, desaturated cold
color palette, horror movie aesthetic, 2.39:1,
psychological horror style
```

### Example 5: Comedy Scene
```
Medium shot of waiter accidentally slipping on wet floor,
tray of dishes flying in slow motion, other diners
looking up in shock, bright cheerful restaurant interior,
overhead natural window light, timing perfect for comedy,
physical humor, bright and colorful, mainstream
comedy style, 1.85:1, studio production
```
