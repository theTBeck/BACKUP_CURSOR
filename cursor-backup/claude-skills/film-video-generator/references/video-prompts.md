# Video Prompt Guide

## Video vs Image Prompts

### Key Differences
- Video prompts need **action/movement**
- Include **duration** (3-30 seconds)
- Specify **camera movement**
- Describe **temporal elements** (start, middle, end)

### Image Prompt
```
Close-up of woman's face, dramatic lighting
```

### Video Prompt
```
Close-up of woman's face, camera slowly pushing in,
tears forming and falling, emotional performance,
soft natural lighting, 10 seconds duration, film quality
```

## Camera Movements in Video

### Static
```
Static wide shot, camera doesn't move
```

### Tracking
```
Tracking shot following subject walking down hallway
```

### Dolly
```
Dolly in toward subject, revealing details
```

### Crane
```
Crane up and away revealing full room
```

### Handheld
```
Handheld close-up, slight shake, documentary feel
```

### Pan/Tilt
```
Slow pan left revealing the landscape
```

## Action Descriptions

### Movement
- Walking, running, standing
- Gestures, expressions
- Object interactions

### Timing
- Slow motion
- Real time
- Quick cuts

### Sequence
- Opening with
- Building to
- Culminating in

## Duration Guidelines

| Duration | Best For |
|----------|----------|
| 3-5s | Transitions, inserts |
| 5-10s | Dialogue moments |
| 10-20s | Complex scenes |
| 20-30s | Feature moments |

## Prompt Templates

### Template 1: Dialogue Scene
```
[Shot type] of [character(s)] in [setting],
[action], [dialogue context],
[camera movement], [lighting],
[mood], [duration] seconds
```

### Template 2: Action Sequence
```
[Shot type] of [action sequence],
[movement description],
[camera operator style],
[pace and energy], [duration] seconds
```

### Template 3: Establishing Shot
```
[Drone/camera] [movement] over/through [location],
[time of day], [weather],
[energy], [duration] seconds
```

### Template 4: Emotional Moment
```
Close-up on [subject], [emotion description],
[camera movement], [lighting quality],
[mood], [duration] seconds
```

## Scene Type Prompts

### Dialogue Scene
```
Medium shot of two people sitting across table from
each other, tense conversation, nervous gestures,
soft overhead restaurant lighting, natural color
grading, 15 seconds, real time, cinematic drama
```

### Action Scene
```
Handheld tracking shot running through crowded
city streets, dodging obstacles, quick pans between
pursuer and pursued, high energy, urban night
setting, neon lights, 20 seconds, action movie style
```

### Romantic Scene
```
Slow dolly toward couple embracing in rain, warm
streetlight creating glow, soft focus background,
emotional intimacy, golden hour color, 12 seconds,
romantic drama style
```

### Horror Scene
```
Static wide shot of empty hallway, flickering light
at far end, ominous atmosphere, slow building tension,
cold color palette, 15 seconds, horror movie style
```

### Comedy Scene
```
Medium shot of waiter carrying overloaded tray,
slight wobble becoming full spill, slow motion
comedy beat, bright cheerful setting, physical humor,
10 seconds, mainstream comedy style
```

### Transition
```
Slow cross-dissolve from object in foreground to
wide establishing shot, dreamlike quality, ethereal
glow, 5 seconds, seamless transition
```

## Common Issues

### Problem: Too Static
**Solution:** Add camera movement or subject movement

### Problem: Too Vague
**Solution:** Specify exact actions, expressions, lighting

### Problem: Wrong Duration
**Solution:** Adjust - longer for complex, shorter for simple

### Problem: Mood Mismatch
**Solution:** Add more mood descriptors, lighting specifics

## Quality Checklist

- [ ] Includes movement (camera or subject)
- [ ] Has clear action/sequence
- [ ] Duration specified
- [ ] Lighting described
- [ ] Mood/emotion included
- [ ] Shot type specified
- [ ] Technical specs (aspect ratio if needed)
