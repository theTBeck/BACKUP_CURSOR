# Coverage Patterns by Scene Type

## Standard 2-Person Dialogue

### Scene Setup
```
INTERVAL - CONFERENCE ROOM - DAY
Characters: MALE (40s), FEMALE (30s)
Tone: Tense negotiation
```

### Coverage Plan

| Shot | Type | Duration | Notes |
|------|------|----------|-------|
| 1 | Establishing WS | 5-8s | Room, positions |
| 2 | OTS Male over Female shoulder | 15-20s | Male reacting to Female |
| 3 | OTS Female over Male shoulder | 15-20s | Female reacting to Male |
| 4 | MCU Female | 8-10s | Key line delivery |
| 5 | MCU Male | 8-10s | Response |
| 6 | CU Female hands (on table) | 3-5s | Tension beat |
| 7 | CU Male (thinking) | 5-8s | Internal conflict |
| 8 | Cutaway: Clock on wall | 2-3s | Time pressure |
| 9 | Final OTS two-shot | 10-15s | Resolution |

## Emotional Monologue

### Setup
```
INT. APARTMENT - LIVING ROOM - NIGHT
Character: JOHN (50s), alone
Tone: Vulnerable, reflective
```

### Coverage Plan

| Shot | Type | Movement | Notes |
|------|------|----------|-------|
| 1 | WS (doorframe silhouette) | Static, wide | Enter, alone |
| 2 | MS sitting in chair | Slow push-in | Settled |
| 3 | CU hands (gripping glass) | Static | Nervousness |
| 4 | MCU face (looking away) | Static | Reflecting |
| 5 | OTS chair + window | Static | Loneliness |
| 6 | CU (eyes) | Hold | Emotion |
| 7 | ECU: Photo in hands | Insert | Memory |
| 8 | CU face (eyes wet) | Hold | Breakdown |
| 9 | MS: Head in hands | Static | Collapse |

## Horror Scene

### Setup
```
INT. BASEMENT - NIGHT
Character: SARAH (20s)
Tone: Dread, terror
```

### Coverage Plan

| Shot | Type | Notes |
|------|------|-------|
| 1 | WS (empty basement) | Establishing dread |
| 2 | MS Sarah descending stairs | Tracking, slow |
| 3 | CU Footsteps | Sound sync insert |
| 4 | OTS over shoulder | What does she see? |
| 5 | Point-of-view: Darkness | Subverting expectation |
| 6 | CU Face (listening) | Pure terror |
| 7 | Handheld: Backing up | Escape instinct |
| 8 | CU: Flickering light | Cut to black |
| 9 | ECU: Mouth (screaming) | Final beat |

## Sequence Example: Heist Planning

### Coverage Flow
```
1. MAP/WIDE: Table with blueprints (establish)
2. MCU: Leader explaining
3. OTS: Hacker at laptop
4. WS: Full team around table
5. CU: Hands on map (pointing)
6. Insert: Blueprint detail
7. MCU: Wheelman listening
8. OTS: Leader-to-Wheelman
9. CU: Clock (time pressure)
10. WS: Team nod (commitment)
```
