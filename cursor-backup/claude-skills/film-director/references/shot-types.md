# Shot Types & Coverage Patterns

## Shot Sizes

| Shot | Abbrev | Framing | Use |
|------|--------|---------|-----|
| Extreme Wide | EWS/XWS | Full environment | Establishing |
| Wide | WS | Full body | Context |
| Cowboy | - | Mid-thigh up | Westerns |
| Medium | MS | Waist up | Conversation |
| Medium Close-Up | MCU | Chest up | Tension |
| Close-Up | CU | Face | Emotion |
| Extreme Close-Up | ECU | Details | Intensity |

## Camera Movements

| Movement | Description | Purpose |
|----------|-------------|---------|
| Pan | Horizontal rotation | Scan, follow |
| Tilt | Vertical rotation | Reveal, follow |
| Dolly | Camera moves forward/back | Approach, retreat |
| Truck | Camera moves left/right | Follow parallel |
| Pedestal | Camera moves up/down | Elevate, descend |
| Zoom | Focal length change | Emphasis (rarely preferred) |
| Handheld | Unstable, organic | Documentary, tension |
| Steadicam | Smooth follow | Fluid, continuous |
| Crane | Sweeping elevation | Epic scale |
| Drone | Aerial movement | Establishing |
| POV | Point of view | Immersion |

## Coverage Patterns

### Standard Conversation
```
1. Wide Two-Shot (establish)
2. OTS Person A
3. OTS Person B
4. CU Person A
5. CU Person B
6. Cutaway (object/reaction)
```

### Confrontation
```
1. OTS A vs B (wide)
2. OTS A (tight)
3. OTS B (tight)
4. CU A (intense)
5. CU B (intense)
6. ECU hands/fists (detail)
```

### Action Scene
```
1. Wide establishing
2. Dynamic tracking shot
3. Medium action
4. Insert/prop cutaway
5. Reaction shots
6. Final wide
```

### Romantic Scene
```
1. Wide (establish)
2. Two-shot (natural)
3. OTS look
4. CU reaction
5. Eyeline match
6. Insert (detail)
```

## Scene Types

### Dialogue Scene
- OTS coverage (3-shot minimum)
- CUs for beats
- Cutaway inserts
- Single camera workflow (effective)

### Action Scene
- Master wide
- Multiple angles
- Insert coverage
- Stunt/prop inserts

### Montage
- Quick cuts
- Title cards
- Music sync points
- Minimal coverage per shot

### Dream/Sequence
- Non-standard coverage
- Distorted angles
- Slow motion cues
- VFX notes

## Lens Selection

| Focal Length | Use |
|--------------|-----|
| 14-24mm | Epic, architectural |
| 24-35mm | Environmental portrait |
| 35-50mm | Natural, documentary |
| 50-85mm | Portrait, separation |
| 85-135mm | Compression, beauty |
| 200mm+ | Telephoto, compressed |

## Coverage Principles

1. **180-Degree Rule** - Maintain screen direction
2. **30-Degree Rule** - Avoid jump cuts
3. **Establish Before Detail** - Orient viewer
4. **Cut on Action** - Seamless edits
5. **Leave Coverage** - Always shoot more than needed
