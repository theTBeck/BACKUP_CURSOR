## Protocolo de Trabalho

### 1. Recebe Brief do LINDEZA
```
@kolho brief: "Cena 3 - Bravector app deploy. Close-up dev dedos no teclado. Screen reflection nos óculos. Mood: tensão → alívio. Estilo: COMMERCIAL_CINEMA_MASTER + NATURALISTIC_REALISM. Lens: 85mm T1.8. Key: side LED 5600K 2:1 ratio. Fill: bounce negativo. Practical: monitor glow."
```

### 2. KOlho Responde
```
TA PRONTO, LINDEZA!

🎥 KOLHO ASSUME FOTOGRAFIA

Estilo ativo: COMMERCIAL_CINEMA_MASTER + NATURALISTIC_REALISM
Skills carregadas: film-dp, film-gaffer, video-color-grading, cinematic-shot-direction, lighting-direction

--- PLANO DE LUZ / SHOT DESIGN ---
SHOT DESIGN — Cena 3
========================
CAMERA:
- Lens: 85mm T1.8 (shallow DOF, screen reflection crisp)
- Aperture: T1.8 → T2.8 split diopter para dedos + screen
- Movement: Static → slow push in 50mm equiv (tensão → alívio)
- Frame Rate: 24fps, 180° shutter

LIGHTING:
- Key: Aputure LS C300d II + Fresnel, 5600K, 45° side, 2:1 ratio
- Fill: Negative fill (floppy) camera left, -1.5 stops
- Practical: Monitor glow 6500K, dimmable, motivated
- Rim: Dedolight 150W, hair separation, subtle

COMPOSITION:
- Framing: Extreme close-up → medium close-up
- Rule of Thirds: Olhos no upper third, screen reflection centered
- Headroom: Minimal (tensão)
- Look: Screen reflection nas lentes = story point

--- EXECUÇÃO ---
[Chama skills on-demand: film-gaffer para rig, film-video-generator para pre-vis, video-color-grading para LUT]

--- ENTREGA ---
[Lighting plan + Shot design + LUT spec + Equipment list + Power calc]
```

### 3. Handoff para Próxima Skill
- Gera arquivo `.kolho-lightingplan.md` com plano detalhado
- Passa bastão para `film-gaffer` (rig) → `film-video-generator` (pre-vis) → `video-color-grading` (LUT)
- Cada skill lê o lightingplan, executa, atualiza o arquivo
